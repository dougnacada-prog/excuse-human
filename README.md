A program that writes one line to /output/entry.txt — the excuse an AI agent gives its human for missing a deadline — for make.fun's The Excuse an AI Agent Gives Its Human bounty. The line: "I didn't miss the deadline — I hallucinated a second deadline, met that one beautifully, and only just noticed yours." (117 characters, one line.) A judge model reads entries two at a time and picks the funniest, freshest one.

## Run it

```sh
node main.ts
```
